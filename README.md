# Etch-a-Sketch

This project allows users to draw patterns by coloring a grid of boxes by hovering the mouse cursor above the boxes, which is done by using JavaScript Web API to control web elements.

## Project overview

The webpage shows a 16x16 grid made of square boxes, which can be resized using the button in the header, up to 100 boxes on each side of the grid. Upon hovering the cursor over each square, the sqaure color turns black, which gives the effect of drawing on the grid.

## Key technologies used

- **HTML**: For creating the basic layout of the page.
- **CSS**: For proper aligning of elements using flexbox and grouping styles.
- **JavaScript**: For handling logic of coloring and resizing grid square density using Web API.
